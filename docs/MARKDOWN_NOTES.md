# Markdown 学习笔记

视频右上角的笔记入口打开写作窗口。新建笔记默认使用“视频标题＋笔记”，标题可以直接修改。编辑器支持 Markdown 标题、列表、加粗、引用、代码块、链接和图片；点击“完成编辑”进入阅读预览，点击“编辑”继续写作。

“时间戳”把当前视频、分 P 和播放位置插入光标处；同一篇文档允许多次插入，在预览中点击即可跳转。“截图”截取当前显示的画面并插入正文，不会回到新建笔记时的位置。同一视频切换分 P 时可以继续编辑原文档。

输入停止 800 毫秒后自动保存。切换文档、完成编辑和关闭面板会等待保存；写入失败会保留草稿并提示重试。没有修改的预览不会在关闭时覆盖本地内容。

笔记默认属于本地“学习笔记”收藏夹，文件夹按钮可更改归属。收藏夹可以同时保存视频和笔记；笔记默认以预览方式打开，支持改名、编辑、移动、导出和删除。删除普通收藏夹时，笔记会移入默认收藏夹。

单篇或批量导出支持 Markdown；有图片时生成包含图片的 ZIP，解压后可在 Obsidian 等 Markdown 软件中打开。导出后的时间戳为带分 P 和秒数的 B 站网页链接。本地笔记保留毫秒精度。

收藏夹导入／导出兼容原有视频 JSON，并支持包含笔记和图片的 ZIP。导入会预检文件，再按已有收藏夹规则合并；重复笔记保留本机版本。备份文件和解压后的总内容仍受 20 MB 限制，大量图片请分收藏夹导出。

旧笔记首次读取时转换为 Markdown 文档，原时间点和截图插入正文。首次写入前保存原始 JSON 备份。新版不会再因超过 500 条而自动移除旧笔记。

## 验证与构建

使用 Flutter 3.44.6。运行 `flutter pub get`、`flutter analyze --no-pub`、`flutter test --no-pub`；Windows 需要 Visual Studio C++ 桌面构建工具，运行 `flutter build windows --release --no-pub`。

本轮本地验证只使用测试数据；未替换原安装目录中的程序。真实 B 站登录、视频播放及系统截图仍需在构建后的客户端验收。
